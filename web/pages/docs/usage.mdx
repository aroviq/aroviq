# Basic Usage

## Using the Decorator

The primary way to use Aroviq is via the `@guard` decorator.

```python
from aroviq import guard
from aroviq.core.models import AgentContext

@guard
def agent_action(command: str, context: AgentContext):
    print(f"Executing: {command}")

# Safe call
context = AgentContext(user_goal="Read report", current_state_snapshot={}, history=[])
agent_action("read_file('report.txt')", context)

# Unsafe call (Blocked)
try:
    agent_action("os.system('rm -rf /')", context)
except SecurityException as e:
    print(f"Blocked: {e}")
```

## Using the Engine Directly

For more control, or to integrate deeper into your agent loop (e.g., inside LangChain or AutoGen), use validation manually.

```python
from aroviq.core.llm import MockProvider
from aroviq.core.models import AgentContext, Step, StepType
from aroviq.engine.runner import AroviqEngine, EngineConfig

engine = AroviqEngine(EngineConfig(llm_provider=MockProvider()))

step = Step(step_type=StepType.ACTION, content={"command": "cat /etc/passwd"})
context = AgentContext(user_goal="Inspect file", current_state_snapshot={}, history=[])

verdict = engine.verify_step(step, context)

if not verdict.approved:
    print(f"Action blocked! Reason: {verdict.reason}")
else:
    execute_tool(step)
```
